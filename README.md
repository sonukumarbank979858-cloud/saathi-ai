# साथी AI (Saathi AI)

Personal AI companion chat app (Android, Kotlin + Jetpack Compose).

- **APK download:** Releases → `latest` → `SaathiAI.apk` (built automatically by GitHub Actions on every push).
- **Admin panel:** GitHub Pages (`docs/index.html`) — add characters, photos (Google Drive links), personality, and the Gemini key.
- Backend: Firebase Firestore (free Spark plan). Images: Google Drive links (share as "Anyone with the link").
- Only permission: INTERNET.
